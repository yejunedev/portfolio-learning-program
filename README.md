## 🚀 2. 실행 방법

Node.js, npm 등의 별도 패키지 빌드나 서버 구동 없이 즉시 실행할 수 있습니다.

1. GitHub 저장소 우측 상단의 초록색 **`< > Code`** 버튼을 클릭합니다.
2. **`Download ZIP`**을 눌러 압축 파일을 다운로드하고 압축을 풉니다.
3. 폴더 안의 **`start.html`** 파일을 더블 클릭하여 웹 브라우저(Chrome 권장)로 실행합니다.  
   *(VS Code 환경에서는 `start.html` 우클릭 후 **Open with Live Server**로 실행하셔도 됩니다.)*

## 📖 3. 이용 순서 및 주요 검증 포인트

1. **시작 및 로그인 (`start.html` → `login.html`)**
   - **[만들기]** 클릭 후 제공된 테스트 계정으로 로그인합니다.
2. **마이페이지 대시보드 (`myPage.html`)**
   - 저장된 포트폴리오 목록을 확인하고, **[+ New Project]**를 클릭해 새 포트폴리오를 작성합니다.
3. **정보 입력 (`input.html`)**
   - 프로필 사진, 인적사항, 기술 스택(엔터/칩 클릭), 프로젝트, 자격증 정보를 입력합니다.
   - **데이터 보존**: LocalStorage 기반으로 동작하여 작성 도중 새로고침하거나 창을 닫아도 내용이 안전하게 복원됩니다.
   - 작성을 마친 후 하단의 **[다음]**을 클릭합니다.
4. **템플릿 테마 선택 (`template.html`)**
   - 지원 직무와 취향에 맞는 4가지 디자인 테마 중 원하는 스타일을 선택합니다.
5. **결과 확인 및 PDF 저장 (`main1~4.html`)**
   - 입력한 데이터가 선택한 테마 레이아웃에 맞춰 실시간 렌더링된 화면을 확인합니다.
   - **[수정하기]**로 입력 폼 복귀 및 내용 재수정이 가능합니다.
   - **[PDF로 저장]** 클릭 시 CSS 인쇄 최적화(`@media print`)를 통해 불필요한 UI가 제외된 깔끔한 A4 규격 문서로 출력/저장됩니다.
