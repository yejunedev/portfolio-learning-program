# 🌐 Follearn (폴런) - portfolio-learning-program (사용자 맞춤형 웹 포트폴리오 빌더)



---

## 📌 1. 프로젝트 개요 (Introduction)

### 1) 기획 배경 및 문제 정의 (Background & Problem Definition)
* **포트폴리오 제작의 높은 진입장벽**: 취업 및 진학을 준비하는 개발 입문자나 IT 전공 학생들은 포트폴리오의 필요성을 절감하지만, 웹 퍼블리싱이나 반응형 레이아웃 설계에 익숙하지 않아 기획 단계에서 많은 시간과 에너지를 소모합니다.
* **비효율적인 문서 관리**: 노션, 워드, PPT 등 다양한 툴로 흩어져 관리되는 프로젝트 이력은 일관된 시각적 브랜딩을 제공하기 어렵고, 실물 제출(PDF)과 웹 링크 공유 간의 포맷 불일치 문제가 빈번히 발생합니다.
* **실시간 편집과 보존의 부재**: 작성 도중 브라우저가 종료되거나 화면이 새로고침될 때 입력 중이던 데이터가 유실되는 불안정성이 기존 웹 기반 빌더의 주요 불편 사항이었습니다.

### 2) 서비스 목적 및 해결 방안 (Objectives & Solution)
* **Follearn(폴런)**은 복잡한 CSS 코딩이나 디자인 툴 다루기 없이, **오직 내용 작성에만 집중할 수 있도록 돕는 원스톱 웹 포트폴리오 빌더**입니다.
* 정형화된 입력 폼을 통해 기본 프로필, 기술 스택, 프로젝트 성과, 자격증 데이터를 입력하면 **실시간 캐싱 엔진**을 거쳐 4종의 고유 테마 템플릿에 맞춰 즉시 최적화된 레이아웃으로 렌더링됩니다.
* 완성된 결과물은 마이페이지 대시보드에 슬롯 단위로 누적 보관되어 언제든 수정·열람할 수 있으며, 인쇄 전용 스타일 시트(`@media print`)를 내장하여 실물 제출용 **규격 PDF 문서로 원클릭 출력**이 가능합니다.

### 3) 기대 효과 (Expected Impact)
* **제작 시간 단축**: 포트폴리오 기획 및 디자인 코딩 시간을 90% 이상 단축하여 프로젝트의 본질적 내용(트러블슈팅, 기술적 기여도) 전달에 집중 가능.
* **직무별 맞춤 브랜딩**: 4가지 특색 있는 테마를 지원하여 프론트엔드, 백엔드, 모바일, 데이터 등 지원 직무와 개인 스타일에 맞춘 포트폴리오 선택권 제공.
* **데이터 영속성 보장**: 브라우저 기반 로컬 스토리지를 활용하여 네트워크 지연이나 우발적 페이지 이탈 시에도 작성 데이터를 100% 안전하게 보호.

## 📖 4. 서비스 이용 가이드 (User Guide)

Follearn(폴런)의 전체 서비스 이용 순서입니다.

### 1. 시작 및 로그인
- `start.html`에서 **[만들기]** 클릭
- 로그인 및 회원가입 진행(`login.html`)
  *(채점용 테스트 계정: `mirim@gmail.com` / `123456`)*

### 2. 마이페이지 대시보드 (`myPage.html`)
- 내 포트폴리오 목록, 서비스 소개, 템플릿 구성 안내 확인
- **[+ New Project]** 버튼을 눌러 새 포트폴리오 제작 시작

### 3. 정보 작성 (`input.html`)
- 프로필 사진, 기본 정보, 기술 스택(엔터 또는 칩 클릭), 프로젝트, 자격증, 소셜 링크 입력
- **데이터 보존**: 입력 중 창을 닫거나 나갔다 들어와도 작성 내용이 그대로 복원 (임시 저장/전체 초기화 지원)
- 작성을 마친 뒤 하단 **[다음 →]** 클릭

### 4. 템플릿 선택 (`template.html`)
- 4가지 고유 테마 중 원하는 스타일의 **[선택하기]** 클릭

### 5. 결과 확인, 수정 및 저장 (`main1~4.html`)
- **실시간 적용**: 선택한 템플릿에 입력한 정보가 즉시 렌더링
- **직접 수정**: **[수정하기]** 버튼으로 언제든 입력 폼으로 이동해 편집 가능
- **PDF 저장**: **[PDF로 저장]** 클릭 시 불필요한 UI가 제외된 규격 문서로 출력
- **보관**: 작업 중 화면을 나가도 `myPage.html`에 프로젝트가 자동 보관되어 언제든 재열람/관리 가능
